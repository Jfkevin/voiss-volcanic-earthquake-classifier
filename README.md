# VOISS — Volcanic Earthquake Classification System

Streamlit research prototype for volcanic seismic event classification using SeismicNet (CNN 1D), VOISS-Net (CNN 2D), and Seismic-VOISS-Net Multimodal CNN.

The application supports waveform/spectrogram visualization, four-class predictions (LP, TC, TR, VT), Compare All model agreement, event metadata, prediction history, and model documentation.

See the project files and `PUBLISH_TO_GITHUB_STREAMLIT.md` for deployment instructions. The three trained `.keras` model files must be added under `artifacts/` using Git LFS.
